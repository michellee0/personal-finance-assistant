# *** Personal Finance & Bill Tracking Assistant ***

> A dynamic web application developed to maintain personal budget control and smartly track upcoming bill/payment deadlines. Users can save new payments, instantly view total active debts, and receive visual warnings for overdue payments.

---

### ^ Features ^

* **Dynamic Database:** Automatically creates the `fatura_db` database and relevant tables upon the first run.
* **CRUD Operations:** Add new bills, list them, and delete/mark them as paid.
* **Smart Deadline Tracking:** Overdue bills are automatically highlighted in red.
* **Auto Budget Calculation:** The total amount of all active payments is automatically calculated and presented in a summary card.
* **Categorization:** Bills can be categorized (e.g., Home Utilities, Subscriptions, Credit Cards).
* **Responsive Design:** Fully responsive UI using Bootstrap 5 for both desktop and mobile devices.

---

### ^ Tech Stack ^

- **Backend:** PHP (Secure DB connection using PDO)
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Database:** MySQL
- **Icons:** FontAwesome
